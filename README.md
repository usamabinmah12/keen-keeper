## Part 1: 📖 Project Overview & Technologies

### Project Overview

**Keen-Keeper** is a modern friend list management web application that helps users organize and maintain their contacts efficiently. Users can store friend information, view detailed profiles, and interact through communication features such as calls, text messages, and video calls. The application also provides visual insights through charts for a better understanding of contact data.

### Technologies Used

- **React** – Frontend library for building user interfaces
- **HTML5** – Markup language for structuring web pages
- **Tailwind CSS** – Utility-first CSS framework for styling
- **React Router** – Declarative routing for React applications

### Dependencies

- `react`
- `react-dom`
- `react-router-dom`
- `tailwindcss`
- `recharts`

## Part 2: ✨ Key Features & Purpose

### Key Features

#### 👥 Friend List Management
Easily add, view, update, and manage friend information in a user-friendly interface.

#### 📞 Communication Features
Quickly connect with friends using integrated call, text, and video interaction options.

#### 📊 Data Visualization
Visualize friend-related data through interactive pie charts for better insights and analysis.

### Purpose

Keen-Keeper simplifies contact management by combining organization, communication, and data visualization into a single responsive web application.

## Part 3: ⚙️ How to Run Locally & Setup

### Prerequisites

- Node.js (v14 or later)
- npm or yarn package manager

### Installation Steps

```bash
# 1. Clone the repository
git clone https://github.com/your-username/keen-keeper.git

# 2. Navigate to project folder
cd keen-keeper

# 3. Install dependencies
npm install

# 4. Start development server
npm start
